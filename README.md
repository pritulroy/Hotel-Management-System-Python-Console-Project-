# 🏨 Hotel Management System (Python Project)

A simple console-based Hotel Management System built using Python. This project simulates real hotel operations like room booking, checkout, and room management.

---

## ✨ Features
- Automatic room generation (5 floors, 40 rooms)
- Room types: VIP, Medium, Normal
- Room booking system
- Customer details storage
- Checkout with bill calculation
- Real-time room status view

---

## 🛠️ Technologies Used
- Python (Core concepts)
- Dictionaries
- Loops
- Functions
- Conditional statements

---

1. Install Python
2. Run the file:

python hotel.py
